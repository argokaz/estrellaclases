¿Por qué importa el formato? 👁️

❌ Sin formato

todo junto sin espacios ni titulos ni negritas ni listas muy dificil de leer y entender donde empieza cada parte

✅ Con formato

Título claro
• Puntos organizados
• Negrita para lo importante
• Fácil de leer rápido

Un buen formato hace que tu trabajo se entienda aunque el lector tenga poco tiempo.

Listas: viñetas y numeradas 📋

• Viñetas

  • Para cosas que no tienen orden
  • Ejemplo: ingredientes de una receta
  • Botón: el ícono de puntos en la barra

1. Numeradas

  • Para pasos que sí tienen orden
  • Ejemplo: pasos para hacer algo
  • Botón: el ícono de números en la barra

Colores y resaltado 🎨

  • El color de texto cambia el color de las letras (ícono A con línea de color)
  • El resaltado pone color de fondo detrás del texto (ícono del marcador)
  • Usa colores con moderación — demasiados confunden
  • Regla: usa máximo 2 colores distintos por documento

El color debe ayudar a entender, no solo decorar.

La tabla de contenido ✨

  • Si usas Títulos, Google Docs puede crear un índice automático
  • Insertar → Tabla de contenido → elige el estilo
  • Al hacer clic en un título del índice → ¡salta directo!
  • Se actualiza sola si cambias los títulos

Esta es la magia de usar Títulos: el documento se navega solo.
