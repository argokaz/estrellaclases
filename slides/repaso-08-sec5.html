📖 Lo que aprendimos hoy
🎯
Zero-shot prompting
Pedir directamente a la IA sin incluir ejemplos en el prompt. Funciona bien para tareas generales y bien conocidas (resúmenes, traducciones, explicaciones). No es suficiente cuando el formato o los criterios de salida son muy específicos — en esos casos la IA necesita más contexto o ejemplos para replicar lo que esperas.
📋
Few-shot prompting
"Few" = pocos. Incluís 2-3 ejemplos del resultado esperado dentro del prompt para que la IA replique el patrón. Es especialmente útil para clasificación (positivo/negativo/neutro), formato específico (seguir la estructura de un documento) y estilo consistente. La calidad de tus ejemplos determina la calidad del resultado.
🔗
Chain-of-thought
Pedirle a la IA que razone paso a paso antes de dar la respuesta final. La instrucción clave: "Piensa paso a paso antes de responder". Mejora significativamente la precisión en problemas de razonamiento, análisis y argumentación porque obliga al modelo a mostrar su lógica — lo que también te permite detectar errores antes de usar la respuesta.
🏗️
Estructura de un prompt profesional completo
Las 5 partes que maximizan la calidad del output: ROL ("Actúa como…") · CONTEXTO (quién eres, para qué) · TAREA (qué hacer exactamente) · FORMATO (cómo presentar el resultado) · RESTRICCIONES (qué evitar, límites). No siempre se usan las 5 — pero conocerlas permite elegir cuáles incluir según la tarea.
🔄
Iteración de prompts
El primer prompt rara vez es el mejor. Iterar significa evaluar el resultado obtenido, identificar qué falta o sobra, y ajustar el prompt con esa información. No es un fracaso — es el método profesional. La diferencia entre un usuario casual y uno estratégico está en si evalúa y refina, o acepta el primer resultado sin cuestionar.
📚 Palabras clave
Zero-shot
Técnica de prompting que pide directamente sin incluir ejemplos. Efectiva para tareas generales; insuficiente cuando se necesita replicar un patrón específico.
Few-shot
Técnica que incluye 2-3 ejemplos del output esperado dentro del prompt para que la IA replique el patrón o formato con precisión.
Chain-of-thought
Técnica que pide a la IA razonar paso a paso antes de dar la respuesta final. Mejora la precisión en problemas de razonamiento y análisis complejo.
Rol
Instrucción que asigna una perspectiva o identidad a la IA ("Actúa como…"). Alinea el tono, vocabulario y enfoque de la respuesta con el contexto necesario.
Restricción
Parte del prompt que define límites o condiciones del output: "sin tecnicismos", "máximo 150 palabras", "no incluyas X". Evita que la IA se desvíe del objetivo.
Iteración
Proceso de refinar un prompt con base en los resultados obtenidos. Evaluar → ajustar → volver a probar. Es el método estándar del prompting profesional.
Prompt engineering
La disciplina de diseñar prompts de forma estructurada y estratégica para obtener outputs de calidad consistente de sistemas de IA generativa.
Output
El resultado producido por la IA en respuesta a un prompt. La calidad del output depende directamente de la claridad, estructura y especificidad del prompt.
