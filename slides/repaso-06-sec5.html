📖 Lo que aprendimos
📌
KPI
Key Performance Indicator. Métrica que indica si se está cumpliendo un objetivo. Solo medir lo que realmente importa para decidir.
📊
Dashboard
Conjunto de gráficos que responde preguntas específicas de un vistazo. Cada gráfico debe responder una pregunta. Si no responde ninguna, sobra.
🔎
Segmentación
Dividir los datos en grupos para comparar su comportamiento. AVERAGEIF(rango_criterio, criterio, rango_valores) para promedios por segmento.
💡
Insight accionable
Descripción + implicación + recomendación. Va más allá de describir el gráfico — propone qué hacer con el hallazgo.
🎨
Formato profesional
Títulos informativos, colores coherentes, gráficos alineados, conclusión debajo de cada uno.
📚 Palabras clave
KPI
Key Performance Indicator. Indicador clave que mide el avance hacia un objetivo.
Dashboard
Hoja con múltiples gráficos organizados para una visión general.
Segmentación
Dividir datos en grupos (secciones, géneros, meses) para comparar.
AVERAGEIF()
Función que calcula el promedio de un rango solo para celdas que cumplen una condición.
Insight
Hallazgo útil de los datos que incluye descripción + implicación + recomendación.
Barras agrupadas
Gráfico de barras que compara múltiples series de datos lado a lado.

Ejercicio 1

Define los KPIs

Para un dashboard de rendimiento escolar, define 3 KPIs. Para cada uno indica: nombre del KPI, qué mide y qué tipo de gráfico usarías.

Respuesta modeloEjemplo: 1) % aprobados por sección → circular o barras por sección. 2) Evolución del promedio mensual → líneas por mes. 3) Asistencia promedio por alumno → barras ordenadas de mayor a menor.
Ejercicio 2

Escribe la fórmula

Para una tabla con sección en columna B (valores: '3A','3B','3C') y notas en columna C (filas 2 a 100): 1. Promedio de notas de 3.°A 2. Promedio de notas de 3.°B 3. Cuenta cuántos alumnos de 3.°C tienen nota >= 14

Respuesta modelo1. =AVERAGEIF(B2:B100,"3A",C2:C100) 2. =AVERAGEIF(B2:B100,"3B",C2:C100) 3. =COUNTIFS(B2:B100,"3C",C2:C100,">=14")
Ejercicio 3

Transforma en insight

El gráfico muestra: 3.°A promedio 15.2, 3.°B promedio 11.4, 3.°C promedio 12.8. Reescribe la siguiente descripción como un insight accionable: 'Los tres salones tienen promedios diferentes. 3.°A tiene el más alto y 3.°B el más bajo.'

Respuesta modeloEjemplo: '3.°A supera en 3.8 puntos a 3.°B, la mayor brecha de la sección. Esta diferencia sugiere que factores como metodología docente o asistencia pueden estar impactando el rendimiento de 3.°B. Recomendación: identificar los alumnos en riesgo de 3.°B y aplicar refuerzo focalizado antes del próximo examen.'
