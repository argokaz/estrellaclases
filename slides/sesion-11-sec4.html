¿Qué es un informe?

Un informe presenta datos analizados de forma ordenada para que el lector entienda qué pasó y qué conclusión sacar.

  • No es una opinión: se apoya en datos
  • Tiene una estructura clara
  • Usa gráficos para mostrar evidencia

De Sheets a Docs 📊

  • Crea el gráfico en Sheets
  • Cópialo (Ctrl+C) y pégalo en Docs
  • Elige "Vincular a la hoja": si cambian los datos, se actualiza
  • O pégalo como imagen si no cambiará

Conclusiones basadas en evidencia 🎯

  • La conclusión resume lo que muestran los datos
  • Cada afirmación se apoya en un dato del informe
  • Nada de inventar lo que los datos no dicen
  • Puede sugerir una acción o recomendación

💡 Datos + interpretación = informe

"Un gráfico sin análisis es decoración. Un informe convierte datos en una conclusión que alguien puede usar para decidir."

  • Estructura clara: intro, datos, análisis, conclusión
  • Cada gráfico va acompañado de su explicación
  • Las conclusiones se apoyan en evidencia
